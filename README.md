# SpotifyForged

React 18 + Vite + TypeScript rewrite of [angular-spotify](https://github.com/trungvose/angular-spotify).

**Forge:** REF-2126 · WO-001 scaffold

## Scripts

```bash
npm install
npm run dev      # http://localhost:5173
npm run build
npm test
```

## Layout

- `src/app/` — shell, routing (later)
- `src/features/` — feature modules
- `src/shared/` — shared UI and utilities
